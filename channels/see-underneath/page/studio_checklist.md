# Studio session for See Underneath (the agent drives the owner's Chrome; the owner says yes before Publish)

Switch to the See Underneath channel first and confirm its name in the top-right menu.

1. Customisation, Branding, Picture: upload `channels/see-underneath/page/avatar.png`.
2. Customisation, Branding, Banner image: upload `channels/see-underneath/page/banner.png`; check the TV, desktop and
   mobile previews against `page/crops/`.
3. Customisation, Branding, Video watermark: upload `channels/see-underneath/page/watermark.png`, display time
   "Entire video".
4. Customisation, Basic info: paste the description from `about.md`; set the handle from `about.md`.
5. Stop. Show the owner the unpublished page. Publish only on the owner's yes.
6. Settings, Channel, Basic info: country India; keywords from `about.md`. Save.
7. Copy the channel id (`UC...`) from Settings, Channel, Advanced settings into `channel.yaml`.
8. Open the public page logged out on a laptop and a phone width. Picture, banner and description must show.

Not in this pass: trailer, featured video, links, contact email.
